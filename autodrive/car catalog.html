Про дані: Модель, марка та рік випуску отримані напряму з офіційного API NHTSA vPIC (US Dept. of Transportation). NHTSA не надає ціну, тип палива чи коробку передач для загального каталогу моделей (ці поля відсутні в базі — вона реєстраційна, а не комерційна), тому вони позначені як оцінні / демо-дані, згенеровані детерміновано на основі назви моделі. Фото автомобілів підвантажуються через Unsplash Search API за запитом "марка модель".

⚠️ Безпека ключа: Unsplash Client-ID використовується тут напряму в браузері (як демо). Для продакшн-сайту варто проксувати запит через свій бекенд, щоб не світити ключ у публічному JS-коді.
